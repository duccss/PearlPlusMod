## PearlPlus Mod Integration

MC client mod integration for [PearlPlus](https://github.com/duccss/PearlPlus) and [PearlPlusWebAPI](https://github.com/duccss/PearlPlusWebAPI)

Adds a button to the server list GUI for PearlPlus web servers allowing you to load pearls even if chat banned/muted. Requires PearlPlus and PearlPlusWebAPI to be installed. Multiple endpoints can be used but make sure you read which server and bot you're loading a pearl from in the GUI as you may end up loading a pearl for your bot on a different server. The auth token needed is pasted in the zenith console during plugin loading or you can get it from the config file. I do not recommend changing it.
